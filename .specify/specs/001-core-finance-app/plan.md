# Implementation Plan: Core Finance App

**Branch**: `001-core-finance-app` | **Date**: 2026-05-04 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/001-core-finance-app/spec.md`

## Summary

A Chrome-only, offline-first PWA personal finance journaling application. Users record income, expense, and transfer transactions against configurable accounts and categories. All data lives exclusively in IndexedDB. The app is installable on Chrome desktop and Android Chrome, deploys statically to GitHub Pages via CI, and supports ad-hoc and scheduled backup to Google Drive or local download in CSV format. A secondary import path accepts `.mmbak` SQLite backups from the user's existing finance app.

**Primary Dependencies**:
- Vite 6 (build, dev server, GitHub Pages base path)

- vite-plugin-pwa + Workbox (service worker, PWA manifest, cache strategies)
- Google Identity Services + Drive REST API v3 (OAuth + cloud backup)
- Papa Parse 5 (CSV generation and parsing)
- date-fns 3 (date formatting, locale-aware)
- @sqlite.org/sqlite-wasm (in-browser SQLite for .mmbak import)
- Lucide React (icons, shadcn default)

**Storage**: IndexedDB via Dexie.js (sole client-side data store per FR-014)
**Target Platform**: Chrome desktop + Android Chrome only (FR-016)
**Project Type**: PWA SPA, static build deployed to GitHub Pages
**Performance Goals**: Transaction form submit < 500ms; app shell load (installed) < 2s; CSV export of 10k records < 10s (SC-008)
**Constraints**: No server-side runtime; static output only; Chrome-only browser support; all data on-device except user-initiated export; Google Drive OAuth credential injected at build time only

## Complexity Tracking

| Complexity | Why Needed | Simpler Alternative Rejected Because |
|---|---|---|
| Client/server internal separation | User requirement; enforces that UI never calls browser APIs directly | Single-layer approach couples UI to IndexedDB making testing and future refactoring harder |
| WASM SQLite (.mmbak import) | User has 5,194 existing transactions in SQLite format with no CSV export | Requiring manual CSV export from old app is friction; direct import is zero-friction migration |
| Periodic Background Sync | Satisfies scheduled export without requiring the app to be open | Removed because limited Chrome support — used as enhancement only; on-open trigger is the primary mechanism |
| Google Drive OAuth (GIS) | User-specified backup destination | Local download only would be simpler but not durable across browser data loss scenarios |

### Architecture: Client / Server Internal Pattern

The app enforces a strict one-way data flow:

```
React Components (client/)
       ↓  dispatch actions / read selectors
Zustand Stores (store/)
       ↓  call service methods
Server Services (server/services/, server/backup/, server/pwa/)
       ↓  read/write
Dexie IndexedDB (server/db/)
```

**Rule**: `client/` may only import from `store/` and `shared/types/`. It MUST NOT import from `server/` directly. `store/` imports from `server/` and `shared/types/`. `server/` imports from `server/db/` and `shared/types/` only.

### Browser Guard

`browser-guard.ts` runs synchronously before React mounts in `main.tsx`:

```typescript
const ua = navigator.userAgent;
const isChrome = /Chrome\/[\d.]+/.test(ua) && !/Edg\/|OPR\//.test(ua);
if (!isChrome) {
  document.getElementById('root')!.innerHTML = ''; // prevent flash
  window.location.hash = '/unsupported';
}
```

### Service Worker Strategy (Workbox)

| Resource type | Strategy |
|---|---|
| App shell (JS, CSS, HTML) | Cache First |
| Images / icons | Cache First |
| Google APIs (OAuth, Drive) | Network First with cache fallback |
| Everything else | Network First |

### GitHub Actions Deployment

```yaml
# .github/workflows/deploy.yml
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm ci
      - run: npm run build
        env:
          VITE_GOOGLE_CLIENT_ID: ${{ secrets.VITE_GOOGLE_CLIENT_ID }}
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```
